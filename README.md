# 咕咕咪的窝 · 像素猫鸡养成

一只猫头鸡身的金色小怪兽，住在 pixel 小屋里。给它取名、喂食、喝水、摸摸，再陪它聊两句。纯原生 HTML + CSS + Canvas 2D，没有构建工具、没有外部依赖、没有网络请求，所有像素画、音效和背景音乐都是代码生成的。

## 快速开始

**双击 `start.bat`**，它会启动本地服务器并自动打开浏览器。按 `Ctrl + C` 停止。

也可以手动启动：

```powershell
cd d:\VibeCoding\pet-chicken
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

然后访问 <http://localhost:8092/>。端口被占用时会自动顺延（8092–8111），以窗口里打印的地址为准。

支持桌面和手机，建议使用较新的 Chrome / Edge / Safari。

## 怎么玩

1. 第一次进入先给它取个名字（也可以点「咕咕咪 / 鸡米花 / 黄金团子 / 少爷」快速填入）。
2. 它会记住名字，住进小窝。底部有四个互动：
   - **喂食**：打开食盘，选小鱼干 / 玉米粒 / 饭团，提升饱食度和心情。
   - **喝水**：补充水分，顺便咕嘟咕嘟。
   - **摸摸**：提升心情和亲密度，它会眯起眼睛。
   - **聊天**：在右侧聊天面板输入，或点快捷话题。
3. 三个状态条（饱食、水分、心情）会随时间下降。状态低时它会没精神、主动要饭要水；不会死亡，也不会离家出走。
4. 每次互动都会增加亲密度。亲密度从 **Lv.1 陌生小鸡** 一路升到 **Lv.8 终身饭票**，升级时有像素星星和气泡提示。
5. 进度自动保存在浏览器 `localStorage`，刷新、关页面再回来都还在。回来太晚，状态会按离线时间缓慢下降（每项有上限，最多掉一点）。
6. 背景音乐是一段由 WebAudio 现场合成的 16 小节轻音乐循环。浏览器要求先有一次交互才会出声，所以点一下页面就会开始播放；右上角的喇叭同时控制音效和 BGM，切换标签页时音乐会自动暂停。

### 彩蛋 / 闲聊

聊天是本地预设对话引擎，会根据关键词和当前状态（饿不饿、渴不渴、亲密度等级）挑不同台词。快捷话题里有：

> **我要当少爷位**

它会认真回应这句话。心情好、肚子饱的时候，它偶尔也会自己冒出这句。更多话题可以试试「你是猫还是鸡？」「我喜欢你」「你几岁？」「唱个歌」「晚安」。

## 实现说明

- **像素养成屋**：Canvas 固定逻辑分辨率 400×320，用整数矩形、扫描线椭圆/多边形绘制，CSS 放大时使用 `image-rendering: pixelated`，不产生平滑缩放。
- **猫鸡本体**：身体、翅膀、尾巴、鸡爪、猫耳、胡须、鸡冠、肉垂全部代码绘制；呼吸、眨眼、甩尾、歪头、咀嚼、喝水、开心跳都会动。
- **互动反馈**：食物会沿抛物线飞向嘴边，碎屑、爱心、水滴、星星粒子由 Canvas 粒子系统驱动；同时有轻声的 WebAudio 合成音效，可随时静音。
- **像素 BGM**：`MUSIC` 里写了 16 小节的 C 大调轻音乐，包含贝斯、和弦垫、八分音符琶音和一条主旋律，使用三角波、正弦波和方波实时合成。WebAudio 的调度器提前 0.6 秒排音符，静音、切后台时停止，回到页面后重新淡入。
- **状态与时间**：页面可见时每秒衰减；刷新后按 `lastSeen` 计算离线衰减，单次最多扣 30 / 25 / 20 点，避免回来看到一只饿扁的宠物。
- **本地闲聊**：关键词意图匹配 + 话题回复池 + 状态判断 + 防连续复读。聊天记录、名字、状态、音量设置全部保存在本地。
- **布局**：桌面双栏（舞台 + 状态/聊天），窄屏自动堆叠；按钮、弹窗、食盘都适配触摸和键盘操作。
- **服务器**：零依赖 PowerShell HttpListener 静态服务器，正确返回 UTF-8 和静态资源 MIME。

## 想改点什么

- **台词**：`game.js` 里的 `DEFAULT_REPLIES`、`QUICK_CHATS`、`IDLE_*`、`FOODS[].lines`，以及 `generateReply()` 中各个意图分支。
- **背景音乐**：`MUSIC` 里的 `bpm`、`chords`（根音和和弦音）、`arpPatterns` 和 `melody`（step / midi / len）都可以改。步长是八分音符；`AudioKit` 中的 `scheduleMusicStep()` 负责编排，`musicNote()` 负责音色和音量。
- **食物与数值**：`FOODS` 里每种食物的 `hunger / mood / bond`，喂食逻辑在 `feed()`。
- **升级门槛和称号**：`LEVELS` 数组，改 `at` 和 `title` 即可。
- **衰减速度**：`DECAY`（每秒掉点）、`OFFLINE_RATE` 与 `OFFLINE_CAPS`（离线最多掉多少）。
- **配色**：`COLORS` 控制整只宠物，`styles.css` 顶部的 CSS 变量控制界面。
- **画布尺寸**：`W` / `H` 和绘制坐标是配套的，改比例时记得同步 CSS 的 `aspect-ratio`。
- **端口**：运行 `server.ps1 -Port 8095`，或修改文件开头的默认值。

## 说明

- 数据只存在当前浏览器；清除浏览器站点数据会丢失存档。
- 页脚的「重新开始」会清空名字、状态、亲密度和聊天记录，请谨慎点击。
- 没有后端，也没有接入真正的 AI 模型；闲聊完全离线，断网可玩。
